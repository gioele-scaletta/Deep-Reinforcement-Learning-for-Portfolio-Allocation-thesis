# Deep Reinforcement Learning for Portfolio Optimization

MSc thesis — Politecnico di Torino, 2024
**Author:** Gioele Scaletta

## Overview
This thesis studies deep reinforcement learning agents for dynamic equity portfolio allocation:
an agent observes market features and outputs portfolio weights, trained to maximise
risk-adjusted returns net of trading costs, and is evaluated out of sample against standard benchmarks.
